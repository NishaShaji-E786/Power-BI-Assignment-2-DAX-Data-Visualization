# Power-BI-Assignment-2-DAX-Data-Visualization

📌 Project Overview
This project focuses on developing an interactive Power BI dashboard to transform raw data into meaningful insights using DAX calculations and data visualization techniques.

🛠️ Tools & Technologies
Microsoft Power BI
DAX (Data Analysis Expressions)
Data Visualization

⚙️ Features & Implementation
1. Calculated Columns
Created calculated columns to derive additional information from existing datasets.
Used calculated columns to enhance data analysis.
2. Calculated Measures
Developed calculated measures using DAX.
Performed dynamic calculations to generate meaningful business insights.
3. Data Visualization
Created interactive charts and graphs.
Presented key metrics and insights through visual elements.
Designed a user-friendly dashboard for better data understanding.
🎯 Key Learnings
Practical experience with DAX functions.
Understanding the difference between calculated columns and calculated measures.
Improved data visualization and dashboard development skills.
Learned how to convert raw data into meaningful insights.
